# TravelWithUs

A modern, luxury travel package website showcasing Rajasthan's heritage destinations (Jaipur, Jaisalmer, Jodhpur, Udaipur, Bikaner, Ajmer) with tailored day-by-day itineraries, tourist landmarks, and direct WhatsApp booking with Aspak (+91 9024772664).

## 🚀 Built With
- **React 19**
- **Vite**
- **React Router**
- **Lucide Icons**
- **Canvas Confetti**
- **Custom CSS**

## 📦 Getting Started

### Install Dependencies
```bash
npm install
```

### Run Locally
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```
